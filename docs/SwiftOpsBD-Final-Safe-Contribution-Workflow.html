Meaning of “untracked”

An untracked file is simply a file Git has not recorded yet. It does not mean the file has no author or may be assigned to another contributor. All existing untracked source, tests, services, documentation and configuration were created as part of Abdul's local implementation and must be committed by Abdul.

Git cannot recover the chronological order of edits made before the first commit. Abdul may divide a large file with git add -p only when its hunks are independent. Otherwise, commit the final file once with its primary feature. Never commit an unchanged file repeatedly to increase the count.
